# fadilafidina.github.io

Personal portfolio: a retro-desktop site (pixel / Y2K / kidcore, candy pastels).

Plain HTML, CSS and JS, no build step. Open `index.html` in a browser, or run `python3 -m http.server 8000` here and visit http://localhost:8000.

The previous Hugo build is kept in `_old-hugo/`, which GitHub Pages ignores.
